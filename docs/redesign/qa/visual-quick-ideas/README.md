# Reference-led generation and quick ideas

- Uploaded visual references are attached before protected identity assets and are explicitly prioritized for palette, spacing, typography style, lighting and composition.
- Both Campaign and Storyline use more than one visual reference where capacity permits; existing four-reference limits remain. Storyline reserves slots for every selected product and a logo.
- Image generation creates the surrounding design with reserved logo/product panels. Server composition inserts the complete stored original logo/product photographs afterward, keeping aspect ratio, full bounds and transparency. It never asks an image model to repaint these protected sources. JPEG encoding remains necessary for Instagram; this is not a claim of bit-identical exported pixels after proportional scaling/encoding. Backgrounds embedded in uploaded product photos remain intact; there is no background removal, cropping or cleanup of protected files.
- New PNG uploads retain a private byte-identical source (including alpha) alongside the publishing JPEG. Sources are deleted/purged with the main media file, remain pinned by Brand Kit/active drafts, and are included in storage byte totals. PNG files converted before this change cannot have lost original bytes restored; re-upload them for original PNG fidelity.
- Protected placements are recorded per slide and final QC still receives original sources and completed slides. Retrying/revising a slide reapplies original sources.
- Ide cepat now invokes the user's configured Conceptor after cost confirmation, reads selected-account Brand Kit, chosen story memory, the signed-in user's previous proposals and actual published posts, and uses authorized Instagram feed images when available. It creates a detailed editable direction automatically, including objective, audience, hook, story continuation, visual direction, caption structure and CTA. It does not generate an image or publish a post. Other members' private sessions remain excluded. Failures leave the user's direction intact and running generation prevents page disposal until its result is delivered.

Verification: 40 application e2e checks; 56 backend checks; browser cost-dialog → detailed-prompt insertion → existing generation workflow. Tests inspect reference ordering and provider payloads, original-file immutability, proportional composition bounds, source-vs-background pixels, history isolation, paid-action checks and no-publication behavior. Providers are simulated; no real paid API calls or Instagram posts are made in tests. The screenshot uses simulated account data.
