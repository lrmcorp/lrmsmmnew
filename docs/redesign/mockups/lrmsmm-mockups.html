LRMsmm redesign · mockup set v3 · 20 Oct 2026

Every menu, redrawn

43 annotated screens covering every page in the sidebar, with the most depth on Content Generator and Drafts. Each screen has an ID (G1, D3, H1…) that the LLM instruction pack refers to. Orange pins match the numbered notes under each screen. Content is example data unless it says otherwise; accounts, follower counts, the Manisky story and model names come from your workspace.

English only. Every label, message, date and number in the app is in English (dates like "Sat, 1 Nov · 12:15 WIB", numbers like 2,322). Menu names are renamed accordingly (Beranda → Home, Sosmed Generator → Content Generator, Draft Konten → Drafts…).
No emoji in the interface. The app UI uses line icons from the app's icon set, never emoji. Post content is different: generated captions are Indonesian by default (language selectable per account and per session) and may include emoji (Brand Kit toggle, on by default).
